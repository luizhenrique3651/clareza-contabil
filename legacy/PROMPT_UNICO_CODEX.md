# Prompt único para iniciar o novo fluxo no Codex

Leia integralmente o `AGENTS.md` e os documentos de controle do Clareza.

Antes de desenvolver, valide se eles refletem o código e preserve o relatório da Fase 0 já aprovada.

A partir deste momento, use o repositório como fonte persistente de contexto.

Execute integralmente a fase ativa indicada em `docs/ROADMAP_MASTER.md`.

Dentro de cada fase:

- faça baseline;
- implemente somente o escopo autorizado;
- teste progressivamente;
- faça uma segunda revisão adversarial;
- tente quebrar autorização, isolamento, transações e estado;
- corrija automaticamente as falhas encontradas;
- execute o gate completo;
- gere o relatório da fase;
- atualize `docs/ESTADO_ATUAL.md`;
- atualize `docs/ROADMAP_MASTER.md`.

Quando o gate for aprovado e a próxima transição estiver marcada `AUTO_ADVANCE: true`, avance sem esperar que eu copie relatórios ou gere um novo prompt em outro chat.

Quando estiver `AUTO_ADVANCE: false`, pare antes da decisão de alto impacto e me apresente:

1. decisão necessária;
2. opções;
3. recomendação;
4. riscos;
5. impacto;
6. caminho sugerido.

Não declare o Clareza pronto para produção.

Não use dados reais.

Comece pela Fase 1.
